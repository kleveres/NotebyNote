# NoteByNote

Веб-сервис для создания, организации и совместного редактирования заметок с поддержкой папок, тегов, истории версий и модерации публичного контента.

## Документация

* **[Техническое задание и схема базы данных](./tech-spec.md)** — описание предметной области, схема БД (7 таблиц, 3НФ), ограничения целостности, транзакции (`T1`–`T6`), ролевая модель и контракты REST API.

## Основные возможности

* **Организация заметок:** группировка по одноуровневым папкам, фильтрация по тегам, статусам и поиск по заголовку.
* **История изменений:** автоматическое сохранение до 20 последних ревизий при каждом редактировании заметки с возможностью отката к прошлой версии.
* **Совместный доступ:** приватность заметок по умолчанию (`private`), выдача прав на чтение (`read`) или редактирование (`edit`) другим пользователям (`shared`).
* **Модерация и безопасность:** проверка общих заметок модераторами (`blocked` с указанием причины), контроль IP-адресов регистрации и входа.

## Технологический стек

* **Backend:** Go 1.23+, GORM, REST API (OpenAPI 3.0 / Swagger UI)
* **База данных:** PostgreSQL 16
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Инфраструктура:** Docker, Docker Compose, Nginx, GitHub Actions
